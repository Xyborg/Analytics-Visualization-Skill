# Analytics Visualization Skill

A reusable `SKILL.md` package for designing analytical dashboards and visualizations using a decision-first, metric-system approach inspired by JetMetrics.

## Contents

- `SKILL.md` — main instructions
- `references/jetmetrics-method.md` — synthesized JetMetrics methodology
- `references/visual-patterns.md` — recurring dashboard/map visual patterns
- `references/chart-vocabulary.md` — chart selection guide
- `references/review-checklist.md` — dashboard QA checklist
- `references/example-specs.md` — examples for Paid Search, SEO, SaaS retention, and Support
- `references/sources.md` — source provenance and limitation note

## Core principle

Do not start with `Which chart should I draw?`

Start with:

`What recurring decision does this visualization need to make easier?`

Then model the metric system, the drivers, the guardrails, and the useful slices before selecting chart types.
