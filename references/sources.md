# Source notes

The skill is primarily synthesized from public JetMetrics material available in 2025–2026. These links are included for provenance and further reading.

## Core methodology

- How to use metrics maps in dashboards
  https://blog.jetmetrics.io/p/how-to-use-metrics-maps-in-dashboards
  Key ideas used: map as dashboard structure; seven map patterns; aligned trends; local metric neighborhoods; KPI-first views; segment tables beside maps.

- Metric Maps vs Metric Trees — Part 1
  https://blog.jetmetrics.io/p/metric-maps-vs-metric-trees-part
  Key ideas used: map = process model; tree = KPI influence model; workflow-first vs causality-first; map scale vs constrained tree; strategy vs tactics.

- Metric Maps vs Metric Trees — Part 2
  https://blog.jetmetrics.io/p/metric-maps-vs-metric-trees-part-840
  Key ideas used: start from map; derive trees from map branches; maintain both as living artifacts; map for operations/navigation; tree for diagnostics.

- Dashboards in 2026: building one people actually use
  https://blog.jetmetrics.io/p/dashboards-in-2026-building-one-people
  Key ideas used: one job per dashboard; trigger/repeat/decision; outcome key metric; supporting metrics; guardrails; breakdowns and filtering.

- 5 rules to turn a vanity dashboard diagnostic
  https://blog.jetmetrics.io/p/5-rules-to-turn-a-vanity-dashboard
  Key ideas used: cohort-first; pair-by-default; window-explicit; seasonal baseline; segment-cuttable.
